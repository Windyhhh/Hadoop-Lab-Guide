## 🚀 Quick Start | 快速开始

```bash
# Start Hadoop cluster
start-dfs.sh
start-yarn.sh

# Run MapReduce job
hadoop jar WordCount.jar input output

# Hive queries
hive -f queries/analysis.hql
```
